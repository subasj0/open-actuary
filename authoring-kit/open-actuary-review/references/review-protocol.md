# Independent educational review protocol

## Scope and capability

Establish exact subject/edition, partial atoms, stated prerequisites and exclusions. Verify each atom is actually explained and independently assessable. Do not confuse an objective heading or a metadata link with coverage. A bounded pilot does not certify a whole subject or current syllabus.

## Technical pass

Solve before reading the supplied solutions when feasible; if solutions were read first, call the work independent recomputation rather than a blind solve. Reconstruct key results with a fresh representation or check: direct sum versus closed form, cohort account versus per-survivor account, raw events versus risk sets, normal tail probability versus a decision threshold. Check parameter domains, timing, units, dependence/conditioning, normalization, limiting cases and approximation status. Re-run provided scripts but do not treat them as independent proof.

For a judgment task, verify that facts lead through a mechanism to a conditional recommendation; do not reward generic lists or fabricated missing information. For a numerical task, verify the prompt contains all necessary conventions and the result's interpretation is justified.

## Teaching and assessment pass

Name the hard transition and inspect whether the prose carries it. Is notation introduced before use? Is the new representation connected to meaning? Does practice fade support and require method selection or transfer where appropriate? Does the summary introduce new examinable material?

With solutions hidden, map every verb in the declared outcomes to the action the question prompt actually requests. Extra calculations in a model solution do not establish independent practice. Then trace every solution criterion—including interpretation principles—to earlier teaching or a declared prerequisite. Mark the model answer with its own rubric. Sum the non-overlapping marks and confirm full credit is reachable; do not credit the same idea twice or require an unasked fourth insight.

Try one plausible wrong answer. The feedback should diagnose its mechanism and offer a repair destination, not simply announce “incorrect.” Revealing an answer is activity, not evidence of mastery.

## Interactive/browser pass

Use `preview_lesson` and open the returned actual URL. For every interaction:

- State what understanding it adds; if it adds none, recommend simpler reading.
- Test default, meaningful change, boundary, repeated action and reset. Independently verify representative displayed values.
- Check shared/locked scales or reference views make the intended change visibly observable rather than cancelling it through automatic zoom; verify rendered chart labels and working section links.
- Check predictions/debrief/transfer are tied to the objective; simulation is labelled and not sold as proof.
- Use keyboard controls and visible focus, a narrow viewport, reduced-motion behavior and a table/text equivalent. Do not use color alone for results.
- For a custom iframe, confirm controls work, host account/DOM access is blocked, external script/data requests are not required, errors/fallback remain understandable and reported state has no privileged effect.
- Check questions before reveal, feedback, notebook, navigation and saved state if the unit relies on them.

If browser access is absent, say so. An HTML inspection is not a rendered accessibility test; automated accessibility checks are not tests with assistive-technology users.

## Report and gate

Record scope and reviewed revision, evidence/commands actually run, and defects by block ID: blocking, major or minor. Distinguish absent evidence from a demonstrated false claim. Do not average a wrong result away with strong visual design.

Review evidence covers technical, pedagogy, interaction (or justified non-use), accessibility and originality. List sources and independently designed assets/scenarios; no external similarity check means originality has not been externally established. Use `pilot` unless qualified expert review really occurred. Retest an actual repair before changing the status. Representative learner trials remain the next source of evidence beyond agent-only review.
