# Open Actuary authoring kit

The independent app is https://open-actuary.subasj02.workers.dev. Add https://open-actuary.subasj02.workers.dev/mcp as a custom MCP server in ChatGPT, select OAuth with dynamic client registration, and approve it while signed in to the invited author account. No separate AI API key is required. The original ChatGPT Site plugin is a different workspace.

Use `studio_overview` and `get_authoring_contract` first. These portable skills cover authoring, review, and publication. Codex can install the skill folders; in ChatGPT use the connected tools and place the Markdown instructions in a project when desired. Local Codex skills do not automatically install a ChatGPT plugin.

Save new work as drafts. For edits, read the existing course/lesson and supply its current expectedRevision. Only publish when requested, after reviewing the exact saved revision. Imports create drafts and never inherit approval. Preview links point at the independent app; sign in to your author account to see drafts.

The live contract defines the supported content format. The original example is bounded pilot material, not a complete exam course. Design new material from its intended syllabus and learning objectives.
